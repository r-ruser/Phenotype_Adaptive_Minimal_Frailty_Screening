# Follow-up ascertainment scope

1. Selected-wave status 9 explicitly represents unresolved vital status: ELSA 1,546, SHARE 1,161, CHARLS 260 and MHAS 71 at baseline-complete-FI level. An ancillary end-of-life subset supplies dates for some ELSA and SHARE cases. Full registry/administrative death ascertainment would extend that subset.
2. The available ELSA end-of-life file supplies year and disclosure-recoded season; precise death/interview dates are required to anchor deaths occurring during 2021–2023 to each participant’s wave-10 opportunity.
3. SHARE wave-4 country absence is structural. Its source status distinguishes country absence from individual mortality or nonresponse. Israel has zero observed follow-up FIs, so the survivor-conditional weighting target comprises supported country strata.
4. Code 4 identifies alive nonresponse. Further reason categories such as refusal, emigration, institutionalization or inability to trace require corresponding tracking/disposition records.
5. Current IPW estimates describe the inherited eligible baseline cohort, explicitly alive persons and country-supported follow-up. The observed covariates and specified observability model define the availability assumption. A mortality-inclusive composite or unknown-survival estimand requires a separately specified outcome and ascertainment design.
6. The primary ADL endpoint is cohort-specific; the supplied shared-five-task sensitivity provides a common task definition using actual panel items.
7. Seven-condition burden includes lung disease descriptively. Baseline eligibility was constructed using six conditions (hypertension, diabetes, heart disease, cancer, stroke and arthritis) plus age and social-information rules; the methods audit supplies its raw-data verification.
