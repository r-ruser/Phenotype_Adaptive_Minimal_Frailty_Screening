# Detailed supplementary methods

## Population and fixed-wave recovery

The analysis inherits a same-wave baseline backbone reconstructed from the released harmonized files. Eligibility requires baseline age of at least 65 years, a recorded diagnosis of at least one of hypertension, diabetes, heart disease, cancer, stroke, or arthritis, and observed marital status or education. Lung disease contributes to the complete FI where available; the eligibility rule uses the six diagnoses listed above. Gender is recorded as a population descriptor. Ages are used as provided in the harmonized sources, with negative source codes treated as missing.

The source baseline/follow-up prefixes are HRS `r14`/`r15`, ELSA `r9`/`r10`, SHARE `r2`/`r4`, CHARLS `r3`/`r4`, and MHAS `r5`/`r6`. Current participant records were cross-checked with these fixed source fields. Age and all seven available disease fields agreed with the stored analysis backbone. The baseline sampling code was recovered from `scripts/01_recover_same_wave_data.R` in the project repository; the older workspace reconstruction scripts are superseded by this same-wave implementation.

The eligible cohort contains 8,426 HRS, 4,470 ELSA, 12,794 SHARE, 4,473 CHARLS, and 6,607 MHAS participants. The complete-FI population contains 8,349, 4,197, 12,560, 4,021, and 5,827, respectively. The resulting target population consists of adults aged 65 years or older with one or more of the six specified chronic conditions. The manuscript's generalizability statements apply to this population and its observed follow-up samples.

The observed baseline year ranges are HRS 2018–2019, ELSA 2018–2019, SHARE 2006–2010, CHARLS 2015–2016, and MHAS 2018–2019. Follow-up ranges are 2020–2021, 2021–2023, 2011–2012, 2018, and 2021–2022. Median intervals are 2.00, 3.50, 4.25, 3.00, and 3.08 years. SHARE wave 2 had additional country fieldwork years; observed source interview dates therefore describe the actual analytic timing more accurately than a single nominal year.

## Source releases

HRS combines RAND HRS Longitudinal File 2022, Version 1 (documentation May 2025) with Harmonized HRS Version D. ELSA uses Gateway Harmonized ELSA Version H (September 2025); SHARE uses Gateway Harmonized SHARE Version G, constructed from SHARE release 9.0.0 (October 2024); CHARLS uses Harmonized CHARLS Version D (June 2021); and MHAS uses Gateway Harmonized MHAS Version D (May 2025). The released file names and dataset labels appear in `source_dataset_labels.csv`. Release documentation names and dates appear in `codebook_release_evidence.csv`.

## Complete frailty indices

The preparation script considers item-level chronic diseases, basic/instrumental daily function, mobility, affect symptoms, self-rated health, sensory function, falls, pain, incontinence, and BMI where present. The supplied `complete_FI_encoding.csv` enumerates every retained deficit and its baseline/follow-up field names. Education and marital status enter the clinical/social context vector and remain separate from the complete FI deficit set. Aggregate affect scale totals, cognition scores, and grip strength are separate from the retained item-level reference.

A reference candidate is retained when at least 50% of eligible baseline participants have an observed coded deficit and the observed values vary. This rule uses baseline availability and variability; it supplies cohort-specific reference sets of 46, 44, 50, 39, and 43 deficits. The same retained baseline item set supplies each cohort's follow-up FI. The denominator is the number of observed retained deficits, and the score is the mean of their 0–1 values. Calculation requires at least `ceiling(0.8 × number of retained deficits)` observed items: 37, 36, 40, 32, and 35 deficits, respectively. Complete-FI frailty is defined as FI ≥0.25.

Negative numeric source codes and nonfinite values are missing. Binary deficits accept 0/1. Difficulty items accept 0/1/2 and code values above zero as one. Five-level general health codes to `(value−1)/4`. Four-level affect items code to `(value−1)/3`, with positively worded items reversed. Binary positive-affect items are reversed. Sensory values 1–6 code to `min((value−1)/4,1)`. BMI values outside 10–80 are missing; the valid categories are <18.5: 0.75; 18.5–<25: 0; 25–<30: 0.25; 30–<35: 0.50; 35–<40: 0.75; and ≥40: 1. Exact field-specific rules and original value labels are supplied in the mapping.

Where an overall sight item is available, the preparation uses that item in place of separate distance/near sight items. Where a conventional BMI field is available, it takes precedence over measured BMI. The original response-category labels and observed rejected numeric codes are provided for audit. Stata tagged missing values enter R as missing values through `haven`.

## Candidate questions and six-item score

The common bank consists of self-rated health (`shlt`), chair rise (`chaira`), climbing several flights of stairs (`climsa`), stooping/kneeling/crouching (`stoopa`), lifting/carrying (`lifta`), picking up a small coin (`dimea`), reaching/raising arms (`armsa`), dressing (`dressa`), bathing (`batha`), eating (`eata`), bed transfer (`beda`), handling money (`moneya`), taking medication (`medsa`), toileting (`toilta`), preparing meals (`mealsa`), and grocery shopping (`shopa`). Each column is prefixed with `q_` in model inputs. Its 0–1 coding is inherited from the corresponding complete-FI item; the complete 80-row mapping is included.

Universal top six items are lifting/carrying, climbing stairs, self-rated health, chair rise, stooping, and shopping. The order of self-rated health and chair rise varies between training folds. The six-item score is the unweighted mean of observed coded deficits, with at least five observed items. At other lengths, calculation requires `ceiling(0.8k)` observed items; the complete-item sensitivity analysis requires all selected items. The code uses the observed-item denominator for participants with one missing question.

This raw mean represents a brief score on its own empirical scale. The complete-FI 0.25 criterion defines the reference status. FI6 classification uses cutoffs estimated in the four-cohort training samples. The locked cutoffs are 5/12 for ELSA and SHARE and 11/24 for HRS, CHARLS, and MHAS. Within training, the threshold is the type-1 empirical 15th percentile among participants with complete FI ≥0.25, targeting 85% sensitivity. Held-out ties and population differences determine the achieved sensitivity. The six-item candidate length was highlighted after describing all held-out length curves; training-only ranking and exploratory length selection are separate steps.

## XGBoost and cross-fitted SHAP

All learned procedures are fitted in the four training cohorts. XGBoost regresses continuous complete FI on the 16 questionnaire deficits, using `objective=reg:squarederror`, `max_depth=3`, `eta=0.06`, `subsample=0.8`, `colsample_bytree=0.8`, `min_child_weight=15`, `nthread=2`, and 100 boosting rounds. These settings are fixed. Candidate-question missingness is supplied as `NA` to `xgb.DMatrix`; the tree model uses its learned missing-value routing. Equal-weight evaluated scores use the observed-item rule above.

Three inner folds are stratified jointly by cohort and complete-FI frailty status. Each model's TreeSHAP contributions are computed on its inner validation fold using `predcontrib=TRUE`. The mean absolute contribution pooled over all inner validation participants determines the ranking. The final brief score uses selected deficits directly. The XGBoost stage supplies item rankings, and the reported brief-score value is the mean of observed selected deficits.

For held-out HRS, ELSA, SHARE, CHARLS, and MHAS, LCA seeds are 20261220, 20261320, 20261420, 20261520, and 20261620. The universal SHAP split seeds are those values plus nine; the three model seeds add inner-fold indices 1–3. Phenotype-specific SHAP split seeds add 100 plus the class number to the LCA seed; model seeds again add 1–3. The seeds are random-number constants recorded in the code.

## Training latent classes

The eight context indicators are hypertension, diabetes, heart disease, cancer, stroke, arthritis, not married/partnered, and low education. Harmonized marital codes 1–3 indicate married/partnered; codes 4–8 indicate the other category. Education category 1 indicates less than upper secondary education; categories 2–3 indicate higher attainment. Their agreement with source value labels was checked in all five cohorts.

A Bernoulli mixture is fitted to complete context rows in each outer training set. It compresses identical eight-bit response patterns and weights them by their frequencies. Candidate class numbers are 2–6. Each candidate uses five random starts with seed `outer seed + 100k + start`. The custom EM algorithm runs up to 500 iterations and converges when the absolute log-likelihood increment is below `1e−7 × (1 + absolute previous log likelihood)`. Conditional response probabilities are bounded to [1e−6, 1−1e−6] and mixing proportions to at least 1e−8.

The primary eligibility screen for class-number choice requires convergence, entropy ≥0.50, and a minimum assigned class fraction ≥0.03. Among eligible candidates, minimum BIC selects the model. The algorithm's fallback uses minimum class fraction ≥0.02, then all candidates if necessary. The selected models in the stored results satisfy the primary screen. BIC uses `8k + k − 1` fitted parameters and the complete-context training denominator. Entropy is computed from the posterior probabilities with response-pattern frequency weights.

Selected classes are 6, 6, 5, 6, and 6, totaling 29 training-fold classes. These are separate class solutions in five outer folds. Training totals are 26,605, 30,757, 22,394, 30,933, and 29,127; complete-context fitting totals are 25,852, 30,363, 21,679, 30,439, and 28,423. For assignment, the observed context indicators contribute to the class likelihood and missing indicators are marginalized. Maximum posterior assigns the class, with ties resolved by the first class. Class-specific XGBoost/SHAP ranking uses all assigned training participants with complete FI, and the corresponding class ranking supplies held-out top-k scores. Fold-level candidate fit statistics, class sizes, and profiles are actual supplied results.

## Longitudinal outcomes

Follow-up FI frailty is follow-up complete FI ≥0.25. The primary incident ADL outcome uses the released five-task aggregate: HRS `r14adl5a`/`r15adl5a`; ELSA `r9adlfive`/`r10adlfive`; SHARE `r2adlfive`/`r4adlfive`; CHARLS `r3adlfive`/`r4adlfive`; and MHAS `r5adlfive`/`r6adlfive`. Participants enter the incident analysis when baseline count is observed and zero; an observed positive follow-up count defines an event. A missing baseline or follow-up count yields an unavailable outcome.

The five HRS tasks are bathing, dressing, eating, bed transfer, and walking across a room. The four other cohorts use bathing, dressing, eating, bed transfer, and toileting. Thus the primary longitudinal target has a cohort-specific fifth task. The aggregate sources also retain their own component-missingness conventions. The separate harmonized five-component sensitivity analysis reconstructs bathing, dressing, eating, bed transfer, and toileting from the item-level prepared panels and is reported in the new revision results.

RAND and the Gateway summary variables can be calculable from partially observed component items. A baseline aggregate of zero therefore follows the source's aggregate convention. The current preparation cleans source missing/negative aggregate values; item-completeness assessment is a distinct sensitivity analysis. The CHARLS Version D documentation describes five ADLs but contains an extra urinary-control term in the printed formula. The released wave-3/wave-4 five-item counts exactly match the five stated tasks among 20,157/19,454 participants with all five task items observed; urinary-control addition introduces disagreements. The supplied QA establishes the implemented five-task interpretation.

## Performance and descriptive length rules

The primary all-k comparisons use individuals with all universal and phenotype scores calculable, together with the relevant outcome. Concurrent analyses have common sample sizes 8,075, 4,196, 12,552, 3,946, and 5,433. Prospective comparisons add observed outcomes within those common score samples. Rank-based AUROC gives half credit for ties. Pointwise AUROC intervals use 150 participant-bootstrap resamples in the existing length curves; paired phenotype-minus-universal intervals use 500 paired participant-bootstrap resamples. MAE, RMSE, Spearman correlation, and fixed-threshold classification are available in the supplied performance tables.

For a longitudinal outcome, excess-over-chance AUROC retention is `(AUROC_short−0.5)/(AUROC_complete FI−0.5)`. It describes discrimination retention on this outcome. The parsimony rules summarize held-out curves using specified fractions of the maximum concurrent AUROC, Spearman ≥0.80, and follow-up FI retention ≥0.85, with ADL retention added in the second rule. These lengths are descriptive exploratory findings.

The overlap sensitivity removes all 16 candidate items from the reference and evaluates the complete and residual references on the same eligible participants. Removing reference items changes its definition and can change the reference-category membership; the comparison characterizes sensitivity to reference overlap.
